R1.1 — Integrity Closure

## Fixed findings
- **Invalid Publish Date:** Stopped silently falling back to `now` when `publishDate` is invalid or missing. Instead, `partial_failures` is incremented and the missing/invalid entries are discarded. A `SCHEMA_MISMATCH` is yielded as error category if partial or complete failure occurs.
- **Timezone Awareness:** Created `field_validator` in `RequestMetadata` and `Disclosure` that strictly blocks naive datetimes by asserting `tzinfo is not None`.
- **Readiness Gate Mock:** Removed the ability to initialize `readiness` from `__init__` in `KAPYorumEngine`. Created a strictly private `_override_readiness_for_testing()` function to ensure the engine fails-closed automatically without arbitrary bypass.
- **HTTP Result Type Contract:** Fixed the return type of `execute_with_retry` from `Tuple[requests.Response, int, Optional[Exception]]` with a `# type: ignore` hack to a truthful `Tuple[Optional[requests.Response], int, Optional[Exception]]`.
- **Unknown Error Invariant:** Added `UNKNOWN_ERROR` to `ErrorCategory` enum and assigned it correctly in `http_utils.py` for any `RequestException` that does not match predefined classes.
- **Test Coverage:** Included adversarial assertions for HTTP 400, 401, 429, missing date, invalid string date, naive datetime injection, and the unknown error invariant.
